mend — one patch tool for every AI edit format. It applies unified diffs (often with wrong line numbers), SEARCH/REPLACE blocks, V4A patches and JSON tool calls to a tree of text files, to one written specification, changing every file or none. It finds the lines an edit names even when the model drifted their whitespace or indentation, at the first of three matching tiers. Node 22 standard library only, nothing to install, deterministic.

## Run it

```sh
node main.ts [options] [PATCH]
```
